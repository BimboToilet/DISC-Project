Формат опроса (пример) 
{
  "title": "Мой DISC-опрос",
  "description": "Необязательное описание",
  "scales": {
    "D": "Доминирование",
    "I": "Влияние",
    "S": "Постоянство",
    "C": "Соответствие"
  },
  "questions": [
    {
      "id": "q1",
      "text": "Я люблю брать инициативу в свои руки",
      "options": [
        {"text": "Полностью согласен", "scores": {"D": 2, "I": 1}},
        {"text": "Скорее не согласен", "scores": {"S": 2, "C": 1}}
      ]
    }
  ]
}

За каждый выбранный вариант начисляются баллы по шкалам из поля "scores". Шкалы можно задавать любые — алгоритм расчета универсальный.
